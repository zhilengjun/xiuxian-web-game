# 洪荒修仙（Web）

> AI辅助开发：2D 轻量弹幕生存 · 修仙题材 · 浏览器直跑 Demo

# [点击体验](!https://zhilengjun.github.io/xiuxian-web-game/)

## 项目由来

这是一道招聘测试题的作答。

题目要求 3 天内完成，实际只花了 **1 天**就跑通了完整玩法流程。

```
题目：用AI做一个修仙题材的玩法小游戏demo
1.核心玩法自定。
2.必须有换肤系统。
3.要有BOSS关，且BOSS须有狂暴机制，狂暴后必定导致失败。
4.无需完善，有大概样子玩法流程，并符合要求，未提及的视为不限制。
5.要求3天内完成。
```

## 这是什么游戏

- **类型**：2D 轻量弹幕生存（修仙题材）
- **单局时长**：3~5 分钟
- **核心循环**：装配武器 / 法袍 / 法器 → 清 3 轮小怪 → 打吞天老祖 → 躲追踪弹防止石柱被点燃 → 在石柱全燃前击杀 BOSS 即胜，否则 BOSS 狂暴必败
- **装配系统**：御剑 / 南明 / 九霄三系，各含武器（普攻）、法袍（护身技）、法器（大招）三部件，可自由配对，同系三件配对正确激活套装属性（最大生命 +50）

## 怎么玩 / 怎么运行

- **运行**：直接双击 `index.html`，零安装、零构建，浏览器打开即玩（无需服务器、无需命令行）。
- **操作**：WASD 移动；普攻自动锁敌；R 放大招；空格冲刺。

## 技术选型（简述）

原生 JavaScript（ES2020+）+ 浏览器 Canvas 2D，零三方依赖、零构建步骤，靠 `<script>` 顺序加载。所有玩法数值集中在 `src/config/`，美术与音效全部代码化生成（占位几何绘制 + 程序化音效），因此仓库不含任何图片 / 音频文件。

## 当前状态

核心玩法已完整可玩：三系技能、BOSS 三阶段与狂暴、护身技、大招、装配系统、胜负三态判定均已落地，并自带浏览器内自测页（`tests/run.html`、`tests/sim.html`）。
